# X4: Foundations mods

This repository contains a maintained X4 9.00 port of two mods originally
created by Jan Görl / JanPanthera:

- `JP_ScriptLibrary`
- `JP_TradeSubscriptionExplorer`

The original, unmodified mod files were imported from
[JanPanthera/JP_X4Mods_2023](https://github.com/JanPanthera/JP_X4Mods_2023),
upstream commit `fa2c795883890062d05c936bc0077c3d85438249`. The first repository
commit preserves that source baseline; subsequent commits document and
implement the X4 9.00 port.

This is an independent maintenance effort and is not an official Egosoft or
JanPanthera release.

## Repository policy

Extracted X4 game files, saves, logs and other local test data are not part of
this repository. Vanilla files used for compatibility work remain local and
read-only.
